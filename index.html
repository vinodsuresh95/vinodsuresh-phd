Featured Work

Sentinel: The Neuro-Symbolic Firewall for AI Agents

Flagship Project

Stopping Hallucinations with Physics, Not Prompts.

The Problem

Enterprise AI Agents are prone to "hallucinations" that can cause catastrophic failures—from unauthorized financial transactions to dangerous SQL deletions. Standard guardrails are too slow (500ms+) and probabilistic.

The Solution

I architected Sentinel, a deterministic middleware that intercepts agent tool calls and enforces hard logic constraints in <10ms.

Key Results

  • 100% Collision Reduction: Achieved 0% failure rate in autonomous driving simulations (highway-env) compared to a 100% crash rate in baseline PPO agents.
  • Zero-Liability Architecture: Stateless, RAM-only processing ensures no sensitive data retention.
  • Open Source: Released the core engine to the community.
